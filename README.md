# Glowshroom Labyrinth Escape

## Overview
Glowshroom Labyrinth Escape is a survival maze exploration game that combines elements of light versus dark and exploration, created in Unity.
The game's vibrant low-poly, cartoon style immerses players in a mysterious, procedurally generated labyrinth. 
Navigate its shifting corridors, and uncover the secrets hidden within before your glow disappears.

***

## Game Features

### Core Mechanics
- **Maze Exploration**: Navigate a dynamically generated labyrinth with new challenges every run.
- **Time-Based Survival**: Manage health and stamina by collecting energy crystals scattered throughout the maze.

### AI and Procedural Generation
- **Wave Function Collapse Algorithm**: The labyrinth is uniquely generated each playthrough, ensuring a fresh and challenging experience every time.

***

## Visual and Audio Design 

### Style
- **Art Style**: Low-Poly, cartoon visuals created in **Blender**.
- **Thematic Elements**: Vibrant glows

### Audio
- **Atmospheric Sound**: Simple adventure game background sound on loop.

***

## Technical Details

### Game Engine
- **Unity**: Used for game development and mechanics implementation.

### Asset Creation
- **Blender**: Created low-poly assets such as player and enviroment.

***

## Gameplay Goals
1. Guide the Glowshroom through the maze before the light fades.
2. Find the exit and escape the labyrinth to win.

***

## Instructions/Controls

##Movement

- **W/A/S/D**: Move the Glowshroom through the maze.

## Camera

- **Mouse Movement**: Adjust the camera angle to better view your surroundings.

## Pause

- **Press 'P'**: Pause the game and access the menu.

***

## How to Play

1. Clone this repository:
   ```bash
    git clone git@github.com:Sm3ggl3s/Glowshroom-Labyrinth-Escape.git
   ```
2. Open the project in Unity (recommended version: 2022.3.17f1).
3. Build and run the game.
4. Navigate the labyrinth, and escape before the light fades!
